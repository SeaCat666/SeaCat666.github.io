这个脚本我已经折腾 11 天了。

我的 Python 属于看得懂一点，真让我从头写基本靠 AI，iOS API 更是没正经学过。一开始只是想让手机自己打个副本，后面一点点加，自动打怪、回血、切装备、看广告、死亡重来、出错重启，最后搓到了 3000 多行。

目前跑一晚上大概有 6～10 元收益。主要是广告给的钻石和怪物掉的材料，单个也就几分钱、几角钱，架不住它一直刷。前提是这些产出不继续拿去提升自己的装备，直接按收益算。

先说结论：AScript 的连续点击模拟不了这次多指操作，WDA 我也没跑通。最后真正解决问题的，是 iPhone 辅助触控里的“创建新手势”——先手动录好两指动作，再让脚本负责播放。

## 它居然还能自己重启游戏

脚本中间有一段是 AI 加的。碰到怪物无敌、游戏状态不对或者其他救不回来的错误，它会直接杀掉 PSG2，再自己重新打开：

```python
PSG2_BUNDLE = "com.cowbeans.pixelsurvival2"

log("自救: system.app_stop 杀进程 -> 重启")
try:
    system.app_stop(bundle_id=PSG2_BUNDLE)
    log("app_stop 成功")
    time.sleep(1.0)
    system.app_start(bundle_id=PSG2_BUNDLE)
    log("app_start 成功")
except Exception as e:
    log(f"游戏重启失败: {e}")
```

我看到以后稍微有点震惊。原来脚本不只是能在游戏里点点点，连 App 都能自己 stop，再自己 open。以前状态乱了只能等我发现，现在它还能把自己抢救一下。

LINUX DO 有个帖子吐槽 PSG2 是“[百分百的游戏，80% 的反作弊](https://linux.do/t/topic/194656)”，下面还说这游戏每天不玩七八小时都不行。看到这里再看一眼自己的屏幕时间：确实。

## 3000 行最后卡在两根手指

整个脚本目前只需要一次多指操作。

PSG2 里按住攻击键 A 的时候，用另一根手指点开背包，角色就会保持攻击状态。还有一种操作是点背包的瞬间点攻击 A，效果也一样。

手动做很简单，两根手指一起上就行。放到 AScript 里就不行了，`ac.click()` 再快也是先点一个、再点另一个，游戏不认。

我第一反应是让 AI 开两个线程。代码看着挺像那么回事，放到手机上还是两个点击排队执行，游戏根本不认。

## WDA 这条路没走通

查了一圈，iOS 想直接做多指，我找到的路是先把 WDA 跑起来。然后又卡在 XCTest 签名，我这个免费 Apple ID 怎么都签不过，WDA 自然也跑不起来。

AScript 后面又突然改成了 no-WDA。为什么改、里面是什么原理，我也没继续研究。它能点击、滑动、跑脚本就行，只是这一次多指还是做不了。

研究到这里我已经不太想知道为什么了。

## 用辅助触控把这一次补上

最后用的是 iPhone 自带的辅助触控。

实际操作只有四步：

1. 打开“设置”>“辅助功能”>“触控”>“辅助触控”。
2. 进入“创建新手势”，录下“按住攻击 A，同时点背包”的两指动作。
3. 保存手势，并在游戏里手动播放一次，确认触点位置没偏。
4. 脚本需要时点开辅助触控悬浮球，再播放这个手势。

就这么简单。不是让 AScript 真正学会了多指，只是让它去点一个系统已经录好的动作。

坐标、蓝色圆圈这些每台手机都不一样，我也不准备在这里写一堆代码。先在自己手机上手动录好，再让 AI 按着画面点几下就行。

辅助触控不是主角，它只负责把最后一个缺口堵上。
